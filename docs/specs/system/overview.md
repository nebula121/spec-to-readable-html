# システム概要 ＆ スコープ

<!-- @spec:system-overview -->

仕様書（Markdown / プレーンテキスト）を人間可読性の高いHTMLレポートへ変換するエージェントスキル spec-to-readable-html の存在目的およびシステム境界の定義正本。

---

## 1. プロジェクト目的・背景

<!-- @spec:system-purpose -->

| 項目 | 定義内容 |
| :--- | :--- |
| **解決する課題** | Markdownやプレーンテキストで作成された長大・複雑な仕様書は、人間にとって全体構造の把握、ワークフロー・データ構造の俯瞰、意思決定やリスクの読み解きに高い認知的負荷を強いる。 |
| **提供価値・ゴール** | 元仕様の契約（MUST/SHOULD）や厳密性を100%維持したまま、要約・論理構造再編・Mermaid/SVG図解・構造化表・元仕様トレーサビリティを付与した単一ポータブルHTMLをオンデマンド生成し、人間の迅速な理解と合意形成を支援する。 |

---

## 2. システムスコープ

<!-- @spec:system-scope -->

| 区分 | 対象領域・境界条件 (`MUST` / `MUST NOT`) |
| :--- | :--- |
| **対象範囲** | 仕様書の構文解析、構造再編、要約、Mermaid/SVG図解選定、XSS防止エスケープ処理、HTMLテンプレート（`template.html`）への埋め込み、および単一ポータブルHTMLファイルの生成と出力 (`MUST`)。 |
| **対象外** | 仕様書以外の任意ドキュメント変換、外部ホスティングサービスへの直接デプロイ、ブラウザ実行環境外でのPDF/画像バイナリへの直接変換処理 (`MUST NOT`)。 |
