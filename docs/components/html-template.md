# HTMLベーステンプレート ＆ インタラクティブビューア

<!-- @spec:component-html-template -->

生成ドキュメントの視覚デザイン、レスポンシブ組版、および図拡大・ズーム・パン機能を提供するHTML/CSS/JS基盤の定義正本。

---

## 1. 責務と境界

<!-- @spec:component-html-template-scope -->

| 区分 | 対象範囲・境界契約 (`MUST` / `MUST NOT`) |
| :--- | :--- |
| **対象範囲（単一責務）** | デザイントークン（CSSカスタムプロパティ）、レスポンシブ2カラムレイアウト（ヘッダー・目次サイドバー・メインコンテンツ）、UI部品スタイル（カード・バッジ・表・コールアウト・図コンテナ）、図拡大モーダル、およびキーボード/マウス/ホイール/ジェスチャー操作スクリプトの提供 (**MUST**)。 |
| **対象外（非責務・委譲先）** | 変換元仕様書の解析・要約処理（`skill-definition` に委譲）、生成されたHTMLファイルのファイルシステム永続化 (**MUST NOT**)。 |

---

## 2. 公開インターフェース ＆ データ構造

<!-- @spec:component-html-template-interface -->

内部スタイル定義は記載せず、テンプレート置換プレースホルダおよびUI制御クラス・イベントインターフェースを定義する (**MUST**)。

| 公開シンボル / プレースホルダ | 入力 / 型 | 出力 / レンダリング | 事前条件・事後条件 |
| :--- | :--- | :--- | :--- |
| 置換トークン (TITLE / SUBTITLE) | エスケープ済み文字列 | `<title>` タグおよびヘッダー見出し | 文書識別タイトルが設定されること。 |
| 置換トークン (META / TOC) | メタバッジ群、目次アンカーリンクHTML | メタバー、固定目次サイドバー | 見出し階層と連動したリンク構造であること。 |
| 置換トークン (CONTENT) | 生成セクション群HTML | メインコンテンツエリア (`.doc-content`) | セマンティックタグ（`section`, `article`）であること。 |
| `openModal(figure)` / `closeModal()` | クリックイベント / キーボードイベント | モーダルダイアログ開閉 | フォーカス制御とスクロールロックが連動すること。 |
| `zoomBy(delta)` / `fitToView()` | ホイールイベント / ズームボタン操作 | SVG / Mermaid図の拡大・縮小・等倍復帰 | カーソル中心のズームおよびパン移動を保証すること。 |

## 3. ふるまい ＆ 異常系契約

<!-- @spec:component-html-template-contract -->

| 区分 | トリガー・入力条件 | 期待動作・送出エラー (`MUST`) | 状態不変・副作用保証 |
| :---: | :--- | :--- | :--- |
| **正常系** | 図要素クリックまたは `Enter` / `Space` キー押下 | 対象図のSVG/Mermaidノードをモーダルへ複製し、ダイアログを開く (**MUST**)。 | 背景スクロールを固定し、モーダル内へフォーカスを移動する。 |
| **正常系** | `Escape` キー押下または閉じるボタン押下 | モーダルを閉じ、背景スクロール固定を解除する (**MUST**)。 | 直前にフォーカスされていた図要素へフォーカスを復帰する。 |
| **正常系** | `Ctrl` / `Cmd` + ホイールスクロール、または `+` / `-` キー | カーソル位置を中心として図のスケールを拡大/縮小する (**MUST**)。 | ビューポート外への過度な消失を防ぐ境界制限を保つ。 |
| **正常系** | マウスドラッグまたは通常ホイール操作 | 拡大された図をドラッグ/ホイール方向へパン移動する (**MUST**)。 | 非ドラッグ時の誤移動を防止する。 |
| **正常系** | スクロールイベント | 画面内に表示されている見出しに対応する目次リンクへ `.active` クラスを付与する (**MUST**)。 | 常に現在地を示す単一のアクティブ項目を維持する。 |
| **異常系** | 図要素内に有効なSVG/Mermaidノードが不在 | 空モーダルの表示を回避し、コンソールエラーを抑止して安全に復帰する (**MUST**)。 | ページ全体のレンダリングや他UI操作を阻害しない (**MUST NOT**)。 |

## 4. 受入条件 ＆ 検証基準

<!-- @spec:component-html-template-verification -->

| 条件ID | シナリオ（前提・実行操作） | 期待される検証結果 (`MUST`) | 検証テストファイル / ケース |
| :--- | :--- | :--- | :--- |
| `AC-HTML-01` | `.diagram-container` にフォーカスして `Enter` キーを押下 | `#diagramModal` に `.is-open` クラスが付与され、図が拡大表示されること (**MUST**)。 | ブラウザ動作確認およびDOM属性検証 |
| `AC-HTML-02` | モーダル開状態で `Escape` キーを押下 | モーダルが閉じ、直前の `.diagram-container` にフォーカスが戻ること (**MUST**)。 | ブラウザ動作確認および `document.activeElement` 検証 |
| `AC-HTML-03` | 印刷モード（`@media print`）の適用 | 目次サイドバー・モーダル要素・ツールバーが非表示となり、本文が1カラムで印刷されること (**MUST**)。 | 印刷プレビュー検証 |
| `AC-HTML-04` | デザイントークン（`:root` の `--color-*`）の変更 | HTML本文を変更することなく、背景色・アクセントカラー・文字色が一括反映されること (**MUST**)。 | スタイル適用確認 |
